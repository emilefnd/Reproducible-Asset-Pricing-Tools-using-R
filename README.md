# Reproducible Asset Pricing Tools using R

Python reproduction of the **Financial Data** and **Asset Pricing** chapters of [Tidy Finance](https://www.tidy-finance.org/chapters/). I wrote the manual, step-by-step version of each task. The book also offers automated shortcuts through its R package.

## Goal

Strengthen my coding and empirical asset pricing skills by rebuilding a standard research workflow by hand, from raw data to portfolio sorts and cross-sectional regressions.

## Contents

### Financial data
- [Accessing and Managing Financial Data](https://www.tidy-finance.org/chapters/accessing-and-managing-financial-data.html)
- [WRDS, CRSP, and Compustat](https://www.tidy-finance.org/chapters/wrds-crsp-and-compustat.html)

### Asset pricing
- [Beta Estimation](https://www.tidy-finance.org/chapters/beta-estimation.html)
- [Univariate Portfolio Sorts](https://www.tidy-finance.org/chapters/univariate-portfolio-sorts.html)
- [Size Sorts and p-Hacking](https://www.tidy-finance.org/chapters/size-sorts-and-p-hacking.html)
- [Value and Bivariate Sorts](https://www.tidy-finance.org/chapters/value-and-bivariate-sorts.html)
- [Replicating Fama-French Factors](https://www.tidy-finance.org/chapters/replicating-fama-and-french-factors.html)
- [Fama-MacBeth Regressions](https://www.tidy-finance.org/chapters/fama-macbeth-regressions.html)


## Data

Stock and accounting data come from CRSP / Compustat via WRDS mainly. The data are licensed and are not included in this repo.
